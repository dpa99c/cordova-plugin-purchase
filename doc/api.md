# API Documentation

## Version 13+

The documentation for the latest version of the plugin is now available here:

 - API reference: https://github.com/j3k0/cordova-plugin-purchase/tree/master/api
 - Guides: https://purchase.cordova.fovea.cc/v/v13.0/
 - Wiki (tutorials, migration guide, ...): https://purchase.cordova.fovea.cc/v/v13.0/

The public `CdvPurchase.Store` API includes `registerNativeLogCallback`,
`getAppStoreReceipt`, and `setAppStoreReceipt`. The native logging callback is
available on Cordova iOS and Android. Raw receipt access is available on the
Cordova StoreKit 1 bridge only; receipt values are base64 strings held in native
memory and imported values are validated before caching.
